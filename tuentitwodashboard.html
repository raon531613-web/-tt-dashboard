📄

PDR

Product Definition Report · 퉤니투

상황, 맥락 설명

롯데홈쇼핑 엘라이브 대학대전을 진행하기 위해 MD부터 타겟팅, 경영전략, 실제 방송까지 이어지는 프로젝트를 수행하며, 이를 뒷받침할 대시보드를 만들고자 함.

문제 정의

⚠️

롯데홈쇼핑 프로젝트의 데이터와 업무 과정이 역할별로 분절되어 있어, 구성원들은 데이터를 반복적으로 탐색·전달해야 하고 프로젝트의 전체적인 진행과 의사결정 과정을 공유하기 어렵다. 또한 교수님, 벤더사, 협력사 등 외부 이해관계자에게 업무를 공유하기도 어렵다.

이 대시보드를 사용할 사용자

퉤니투 · 벤더사 · 교수님 · (향후) 이 대시보드를 확인할 채용담당자

해결 방안

우리가 넣고 싶은 데이터를 매번 찾아야 하는 번거로움, 역할이 나눠져 있어 서로의 진행상황을 파악하기 어려운 점, 다른 역할의 데이터를 받는 번거로움, 벤더사·교수님께 진행상황을 설명하기 어려운 점(낮은 신뢰도)을 하나의 대시보드로 해결한다.

📝 메모

어떤 문제를 해결하는가

넣고 싶은 데이터를 매번 찾아야 하는 번거로움 / 역할이 나뉘어 있어 서로의 진행상황 파악이 어려움 / 다른 역할의 데이터를 받는 번거로움 / 벤더사·교수님께 진행상황을 설명하기 어려움(벤더사의 낮은 신뢰도)

어떤 기능과 경험을 제공하는가

기능설명
자동화수동으로 해야 할 것을 자동화
실시간 공유다른 역할의 진행상황을 실시간으로 공유
외부 공유교수님·벤더사 등 외부 이해관계자에게 잘 공유할 수 있음
포트폴리오화추후 팀원 개인의 포트폴리오로 활용 가능
진행상황 가시화전체 프로젝트 진행상황을 한눈에 확인
데이터 분석개선점 도출을 위한 데이터 분석 (매출액 - 라이브 60분 동안 언제 얼마나 팔렸는지, 이탈률 - 시청자가 언제 이탈했는지 등)
🔭

향후 계획 — 라이브 방송 중 매출액 추이, 시청자 이탈 구간 등 방송 데이터 분석 기능은 실제 방송(11/25, 12/2) 이후 데이터가 쌓이는 대로 이 대시보드에 추가할 예정입니다. 현재 버전은 프로젝트 시작 단계에 맞춰 과제·업무 관리와 일정 공유에 우선 집중했습니다.
